# photosz — зашифрованные фотоальбомы

Основной сценарий — скилл `photo-album` (`.claude/skills/photo-album/SKILL.md`).
Публичные правила — `plan.md`. Личные детали и метрики — `plan.private.md`, его нет в git.

## Хостинг

Основной адрес — Cloudflare Pages (`https://photosz.pages.dev/<slug>/`), загрузка напрямую `tools/cfpages.py`
(без GitHub Actions). Запасной — GitHub Pages (`https://dimmik.github.io/photosz/<slug>/`), он же хранит историю.
`album.py publish` выкладывает в оба места.

## Переезд: папку целиком скопировали на другой компьютер

Признаки: путь проекта другой, или в памяти нет ничего про альбомы (нет `MEMORY.md`), а в папке есть
`.claude-memory/`, `token.txt` и рабочие папки `*/work/`. Также делай это, если пользователь просит
«восстанови», «переехали», «настрой тут». Тогда:

1. `bash tools/restore_here.sh`. Скрипт кладёт память из `.claude-memory/` на место, ставит права 600
   на токены и ключи, настраивает git, без sudo ставит Python-пакеты и в конце проверяет всё,
   токены — живыми запросами. Запускать можно повторно.
2. Если скрипт пишет «НУЖНА УСТАНОВКА», попроси пользователя выполнить `! bash tools/setup.sh`:
   apt-get спросит пароль sudo. Потом снова `bash tools/restore_here.sh`.
3. Память появится только в следующей сессии. В этой сессии прочитай `.claude-memory/MEMORY.md`
   и нужные файлы из той же папки. Особенно важен `never-publish-rita.md`.
4. Цель — «ВСЁ ВОССТАНОВЛЕНО» в конце вывода. Если токен «НЕ РАБОТАЕТ» (отозван или истёк),
   действуй по шагам 3–4 раздела ниже.

`.claude-memory/` — открытая копия памяти внутри папки проекта, в git не попадает. Её обновляет
каждый `backup.py save`, а `publish` вызывает его сам.

## Новый компьютер (папку не переносили, есть только git)

Признак: нет папки `.faces/` и рабочих папок альбомов (`*/work/`). Тогда:

1. `bash tools/setup.sh` ставит Python-библиотеки, ffmpeg и модели лиц и в конце всё проверяет.
   Через этот скрипт не ставятся, их пользователь ставит сам: WSL (Ubuntu 22.04+),
   Chrome в Windows (нужен только для скриншотов проверки), Claude Code.
2. Попросить пользователя выполнить `! python3 tools/backup.py restore`. Фраза вводится скрыто,
   у Claude её нет. Команда восстановит память, `plan.private.md`, справочник лиц, стоп-лист и
   рабочие файлы альбомов (ключи, отбор, правки). Если работа шла с архивом телефона,
   восстановится и `backup/archive.bin`.
3. Попросить пользователя положить в `token.txt` новый fine-grained токен на этот репозиторий:
   Contents, Pages и Administration на запись.
4. Попросить пользователя положить в `claudflare_t.txt` API-токен Cloudflare (Account → Cloudflare Pages → Edit).
   ID аккаунта (`cloudflare.json`) восстановится из копии. Без токена публикация идёт только на GitHub Pages.
5. `bash tools/setup.sh --check` должен показать «стоп-лист есть». Без стоп-листа публикация не пойдёт.

Оригиналов фото в копии нет. Чтобы править старый альбом, пользователь заново кладёт его
зип в папку с тем же именем.
