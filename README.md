# photosz

Зашифрованные фотоальбомы из поездок на GitHub Pages (`https://dimmik.github.io/photosz/<slug>/#k=<ключ>`).

- `<slug>/` — опубликованные альбомы: `index.html` (экран ключа + расшифровщик) и `data/*.bin`
  (AES-256-GCM). Без ключа ничего не видно, страницы с `noindex`.
- `tools/` — пайплайн: зип с фото/видео → метаданные → разделы → контактные листы для дешёвых
  моделей → сборка → шифрование и публикация. Точка входа — `tools/album.py`.
- `.claude/skills/photo-album/` — навык Claude Code, который ведёт весь сценарий.
- `plan.md` — правила, решения и метрики.

Оригиналы, рабочие файлы с ключами и координатами и токен в репозиторий не попадают
(`.gitignore` — белый список).
